TECHNICAL DETAILS
================================================================================

Components:
1. Cloudflared (DoH server)
2. CoreDNS (DNS proxy with caching)
3. WireGuard (VPN server - optional)

Ports Used:
- 53 (DNS) - for Xbox
- 5053 (Internal DoH)
- 8053 (HTTPS DoH endpoint)
- 51820 (WireGuard VPN - optional)

DNS Flow:
Xbox → VPS:53 → CoreDNS → DoH Server → Quad9/OpenDNS → Internet

VPN Flow (if used):
Xbox → PC/Router → VPN tunnel → VPS → Internet
